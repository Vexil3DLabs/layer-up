- 2026-11-08 — Engine functions mutate the state they are given (fast, simple, no copying in the sim). The UI store clones the state (`structuredClone`) before each tick or action and swaps it in.
- 2026-11-08 — `tick(state, dt)` splits long gaps into 5 s steps, so a 24 h offline gap is ~17,000 steps and still runs in well under a second. Offline time is capped at 24 h.
- 2026-11-08 — Failures are rolled when an attempt starts: the roll and the failure point (10%–90% through the print) are fixed then, so the sim and tests are reproducible. Filament for the attempt is taken at the start; the part not yet used is returned to stock if the print fails.
- 2026-11-08 — Wear rises by 1 per print hour of real printing time (`SECONDS_PER_PRINT_HOUR` = 6 s), so a faster printer wears less per job but the same per minute. If wear reaches 100 mid-print the print fails ("broke down") and the printer needs a 10% repair. Maintenance and repair are one Service action; wear resets when service starts, and the printer is offline for 10 s (maintenance) or 20 s (repair).
- 2026-11-08 — The reputation multiplier on payout is applied when a job appears on the board (so the number on the card is the number you get). Reputation: +0.04★ per collected job, −0.25★ per refund (both tunable in `data/economy.ts`).
- 2026-11-08 — No deadlines, rush jobs or late penalties in Milestone 1 (they belong to Milestone 2). Jobs only expire off the board if not taken.
- 2026-11-08 — The balance sim was built in Milestone 1 (the plan says Milestone 2) because `CLAUDE.md` says both `npm run test` and `npm run sim` must pass every session. Tier 2 is not built yet, so the sim measures how long the bots take to *meet Tier 2's unlock requirement* ($1,500 cash + 50 jobs) inside the Garage. The ±50% rule is applied to both bots, not only the best one.
- 2026-11-08 — Tier 2 requirement is reached in ~14–15 min of bot play vs the ~20 min target. Both are inside the allowed 10–30 min, so no numbers were changed. Bots check in every 4–6 s, which is faster than a real player, so I expect human play to land closer to 20. Revisit after Riaan's feedback.
- 2026-11-08 — Job board numbers: 3–5 jobs, a new job every 8 s while there is space, each job stays 70–130 s, board starts with 4. All in `data/economy.ts`.
- 2026-11-08 — After starting a job the UI jumps to the Floor only if no other printer is still free; otherwise it stays on the Job Board so two printers can be loaded quickly.
